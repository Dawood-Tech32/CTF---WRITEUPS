# Intro to Academy — HTB Academy

**Platform:** HackTheBox Academy
**Category:** General / Orientation
**Status:** ✅ Completed

## Overview

A short orientation module covering how HTB Academy itself works — module
structure, difficulty tiers, cube/point system, Pwnbox usage, and how progress
tracking and paths function across the platform. No offensive techniques are
covered here; it's purely platform navigation.

## Topics Covered

- How modules, sections, and tiers are structured (Fundamental → Easy → Medium
  → Hard → Advanced)
- Difference between "Theory" and "Interactive" sections
- Using the built-in Pwnbox vs. connecting your own VM via VPN
- How Cubes, points, and skill assessments contribute to path completion
- Navigating between Academy and the main HTB labs platform

## Key Takeaways

- Interactive sections require an active Pwnbox or VPN connection — theory
  sections don't.
- Skills assessments (end-of-module practical exercises) are required for full
  completion credit, not just reading through the theory.
- Academy paths (e.g. Penetration Tester path) bundle specific modules
  together and track progress separately from standalone module completion.
