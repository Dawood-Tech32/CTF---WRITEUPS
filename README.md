
# CTF Writeups & Methodologies

A collection of methodology-focused writeups from CTF challenges I've solved across 
HackTheBox, Hacker101 (HackerOne), Black Hat MEA CTF, and other platforms.

Rather than full step-by-step solutions, each writeup focuses on:
- Reconnaissance and thought process
- Vulnerability classes identified and how they were confirmed
- Tools and techniques used
- Root cause analysis and mitigation recommendations

This approach respects platform guidelines (no spoilers/flags) while demonstrating 
practical, hands-on security methodology relevant to SOC, penetration testing, and GRC roles.

**Background:** CompTIA Security+ | Google Cybersecurity Professional Certificate | 
Pentest Cyber Specialist Program
